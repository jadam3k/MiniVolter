# MiniVolter
> MiniVolter is just Buck converter from any voltage from 12-60V to 5V. it can be used in automation because chip can handle a lot of current and thats why i made it. I want to use it on my plc project for powering my chip. Project is not hard im placing images for people who want to make it too below. :)
